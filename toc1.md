# Curriculum for Teaching Rust Programming language

1. Introducere în Rust (2 sesiuni)
   - Istoricul și filozofia Rust
   - Instalare și configurare (rustup, cargo)
   - Primul program Rust
   - Concepte fundamentale de safety, concurență și performanță
   - Rust toolchain și ecosystem

2. Fundamentele Limbajului (3 sesiuni)
   - Tipuri de date primitive
   - Variabile și mutabilitate
   - Funcții și control flow
   - Structuri de date de bază
   - Pattern matching
   - Comentarii și documentație

3. Ownership și Borrowing (4 sesiuni)
   - Conceptul de ownership
   - Move vs. Copy
   - Borrowing și referințe
   - Lifetimes
   - Stack vs. Heap
   - Slice type

4. Tipuri Compuse și Pattern Matching (3 sesiuni)
   - Structuri (structs)
   - Enumerări (enums)
   - Pattern matching avansat
   - Option și Result
   - Match expressions
   - Destructuring

5. Traits și Generice (3 sesiuni)
   - Conceptul de traits
   - Implementare traits
   - Generice în funcții și structuri
   - Trait bounds
   - Associated types
   - Default implementations

6. Error Handling și Testing (2 sesiuni)
   - Result și Option în detaliu
   - Custom error types
   - Error propagation
   - Unit testing
   - Integration testing
   - Documentation testing

7. Concurență și Paralelism (3 sesiuni)
   - Threads în Rust
   - Message passing
   - Shared state
   - Async/await
   - Tokio ecosystem
   - Concurrency patterns

8. Collections și Smart Pointers (2 sesiuni)
   - Vec, HashMap, HashSet
   - Box<T>
   - Rc<T>
   - Arc<T>
   - RefCell<T>
   - Performance considerations

9. Project și Package Management (2 sesiuni)
   - Cargo în detaliu
   - Dependencies management
   - Workspaces
   - Publishing crates
   - Documentation
   - Best practices

10. Sisteme și FFI (2 sesiuni)
    - Unsafe Rust
    - Foreign Function Interface
    - Binding-uri C
    - Sistem calls
    - Platform-specific code

11. Rust Ecosystem și Tooling (2 sesiuni)
    - Cargo tools și plugins
    - Rustfmt și Clippy
    - Debugging tools
    - Profiling
    - IDE support
    - Common libraries

12. Proiect Final (3 sesiuni)
    - Design și arhitectură
    - Implementare
    - Testing și optimizare
    - Code review
    - Deployment

Pentru fiecare sesiune recomand:
- 30 minute teorie
- 45 minute exemple practice
- 30 minute exerciții hands-on
- 15 minute Q&A

Exerciții Practice:
- Mini-proiecte după fiecare capitol
- Exerciții de debugging
- Code reviews între colegi
- Provocări săptămânale de programare

Evaluare:
- Exerciții practice săptămânale (40%)
- Proiect intermediar (20%)
- Proiect final (40%)
